Course materials collected while studying the LM051 Computer Systems
degree at the University of Limerick.

## Contents

- `Semester 1` to `Semester 8`: lecture notes, slides, tutorials,
  assignments and code for each module, organised by module code (for
  example `CS4411 - Imperative Programming 1` or
  `CS4226 - Distributed Systems`). There is no Semester 5 folder.
- `docs`: written reports and assignments, including the CS4313
  software engineering project documents.
- `laTex`: archived LaTeX templates, lecture and tutorial sources.
- `other`: the final year project report and other documents.

Most files are PDFs, PowerPoint slides and Word documents, with some
Java, C# and other source code from assignments.

This is an archive of study material, not a buildable project.
